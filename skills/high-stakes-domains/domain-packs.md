# Domain packs

Starting checklists for 58 industries and niches. Grep for the pack that matches the product (for example `banking`, `medical-devices`, `education`). Each row lists what the design must account for; none of them is a complete or certified guide to the domain.

Each must be developed around real roles, terminology, entities, rules, exceptions, context, and evidence. These are coverage specifications, not completed regulated-domain guides or certifications. New niches can extend the same contract.

## Record what you applied

For each applied profile record the supported product/version, actual actors and tasks, data meanings, object states, business rules, permissions, platform/input, language/region, environment, sources, owner, evidence, specialist responsibilities, known gaps and update trigger. Resolve conflicts explicitly.
